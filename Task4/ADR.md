### <a name="_bjrr7veeh80c"></a>**Альтернативы**
 Прямая интеграция через API
Описание: Создать RESTful API для предоставления актуальных ставок.
Недостатки:
1. Необходимость доработки системы кол-центра и партнёрского кол-центра.
2. Высокая сложность внедрения для партнёра.

Автоматический экспорт в CSV
Описание: Ежедневный экспорт ставок в CSV через SFTP.
Преимущества:
1. Простота реализации.
2. Поддерживается партнёрским кол-центром.
3. Минимальные изменения в существующих системах.

Мануальный обмен данными
Описание: Ручной перенос данных из АБС в систему кол-центра.
Недостатки:
1. Высокий риск ошибок.
2. Низкая эффективность при масштабировании.
**Недостатки, ограничения, риски**

Недостатки:
1. Сложность настройки SFTP: Требует дополнительных технических ресурсов.
2. Время настроек партнёра: Партнёрский кол-центр может потребовать времени для адаптации.
Ограничения:
1. Формат данных: Ограниченность в выборе формата (CSV).
2. Частота обновлений: Возможны задержки в обновлении ставок.
Риски:
1. Ошибка в экспорте данных: Неверные ставки могут привести к неправильным консультациям.
2. Проблемы с доступом: Возможные проблемы с доступом к SFTP серверу.


Список крупных задач для каждой системы
1. АБС (Oracle):
- Разработка процедуры экспорта актуальных ставок в CSV.
- Настройка расписания для ежедневного экспорта.
2. SFTP Server:
- Настройка сервера для передачи файлов.
- Создание пользователей с ограниченными правами.
3. Система кол-центра банка:
- Интеграция с новым источником данных (CSV/SFTP).
- Разработка интерфейса для просмотра ставок.
4. Партнёрский кол-центр:
- Настройка клиента SFTP для получения файлов.
- Интеграция данных в существующую систему.
